# Focused diagnostics

These scripts inspect saved plans and imported geometry. They are development tools, not part of
the normal solve-to-simulation pipeline.

Run them from the repository root:

```bash
python3 tools/diagnostics/diagnose_fabrica_interfaces.py --help
python3 tools/diagnostics/diagnose_transition_gate.py --help
python3 tools/diagnostics/audit_fabrica.py --help
python3 tools/diagnostics/fk_compare.py --help
```
